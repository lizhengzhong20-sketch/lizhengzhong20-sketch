## Featured project

### [ScalarPulse](https://github.com/lizhengzhong20-sketch/scalarpulse)

A lightweight local dashboard for watching model-training metrics in real time.

- Track loss, accuracy, learning rate, and custom metrics.
- Use it with PyTorch or any training loop that can report numbers.
- Keep experiment history locally and export data as CSV.
- Start with a small Python API and view everything in the browser.

[View the project →](https://github.com/lizhengzhong20-sketch/scalarpulse)
